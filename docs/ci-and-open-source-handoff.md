# CI and open-source handoff

Pre-change commit: `e9c7554aad2d7eeb19058b8b5d35993dcf7186bc`.

The workflow in `.github/workflows/ci.yml` runs offline Bun tests and TypeScript checks, Svelte diagnostics and disposable Chromium suites on pull requests and pushes to `main`. The guard job builds the inspector first because its command tests serve `inspector/dist`. It uses read-only GitHub permissions, pinned actions, a frozen Bun lockfile, and no TypeSafe key or live evaluator. A passing `main` run saves a local-install archive as a 14-day Actions artifact; it does not publish npm packages, tags, or releases.
