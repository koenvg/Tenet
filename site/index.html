TENET can be wrong. It isn't an OS sandbox.

Your policy is a text file.

Put rules in TENET.md or select another policy file. TENET checks eligible Pi tool calls against them before they run.

Example rule Rule; BLOCK; Never publish code to a remote repository without explicit approval.

Observe

Observe is the default. TENET reports what it finds to you. It does not stop the call or ask for approval.

Enforce

If you opt in to enforcement, a blocking rule can stop a call or ask for native approval. It depends on the assessment.

TENET only checks tool calls it can see through Pi. It does not inspect subprocesses, and its judgments can be wrong. In eligible sessions, it saves submitted evidence locally by default, even when a call passes. That evidence may include code or secrets. Set TENET_RECORDING=off before starting Pi to opt out of new recordings.
