# Tenet development

Tenet is in alpha. Breaking changes are acceptable. Prefer one clear current implementation over compatibility switches, parallel legacy implementations or migration shims, unless the user explicitly requires compatibility for a change.

Keep historical assessment records interpretable using their recorded contract versions. Alpha status does not relax enforcement safety, authenticated-fact requirements or validation.

For implementation and verification, follow [CONTRIBUTING.md](CONTRIBUTING.md). `TENET.md` is policy-guard test data, not instructions for coding agents.

Documentation: before creating or editing a page, read and follow [the writing guide](docs/writing-guide.md). Check every changed page against all 18 manual checklist items before handoff.
