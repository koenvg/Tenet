# Security reports

Please do not open a public Issue, Pull Request, or Discussion for a suspected vulnerability. Use [GitHub's private vulnerability reporting](https://github.com/koenvg/Tenet/security/advisories) instead. It lets you send a report to the maintainer without making the details public. If that option is not available, contact the repository owner privately through their GitHub profile.

TENET is a policy guard, not an OS sandbox. Reports that include policy text, command arguments, local archives, or submitted evidence may contain source code or secrets. Remove credentials and unrelated personal data before sharing a reproduction. The inspector is a local read-only service without authentication; do not expose its port publicly.
