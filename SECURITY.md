# Security reports

Report a suspected vulnerability through [GitHub's private vulnerability reporting](https://github.com/koenvg/Tenet/security/advisories). This sends the details to the maintainer without making them public. Do not open a public Issue, Pull Request, or Discussion.

If private vulnerability reporting is unavailable, contact the repository owner privately through their GitHub profile.

Before sharing a reproduction, remove credentials and unrelated personal data. Policy text, command arguments, local archives and submitted evidence can contain source code or secrets.

TENET is a policy guard, not an OS sandbox. The inspector is a local read-only service without authentication; do not expose its port publicly.
